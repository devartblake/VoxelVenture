# The world gallery

Written for: the owner and developers. Made 2026-11-16 from the screenshots and diagrams kept while the world was built (`node scripts/world/make-gallery.mjs <folder of PNGs>` rebuilds this page and the pictures). The pictures are WebP, 1400 pixels wide at most.

These are working pictures, taken on the development page (`/world/stream`) and in the game with `?world=baked` while each feature was built: many show an earlier stage, and the caption says so where it is known. For what each feature is now, follow the link under its heading.
